# 技术问题追溯

## 目标

回答「上次这个问题我是怎么解的」，并还原**完整的试错路径**，不只是最终答案。

## 步骤

1. `search_screen(keyword="<报错码或关键词>", days=30)` —— 先搜字面。
   报错码、异常类名、接口路径这类**精确串一定用这个**，别走语义检索。
2. 从命中结果拿到时间戳。
3. 对该时刻调 `timeline(days_ago=N, hour_from=H-1, hour_to=H+1)` ——
   **前后各扩一小时**。解法往往不在报错那一刻，而在之后的查文档、改代码里。
4. `read_report(days_ago=N, hour=H)` 读那几个小时的报告。
5. 如果字面搜不到，再用 `recall()` 换个说法问。

## 输出

```
## 问题
原始报错/现象，带上首次出现的时间。

## 试过什么
按时间顺序列出尝试过的路径，包括**走不通的**。
走不通的那些同样有价值 —— 下次不用再试一遍。

## 最终怎么解的
具体做法 + 证据（时间、应用、原文）。

## 如果没找到
明说没找到，列出搜过哪些关键词。不要编一个看起来合理的解法。
```
