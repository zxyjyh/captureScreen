# 注意力去向盘点

## 目标

回答「这段时间我的注意力实际投在了哪几件事上」。
注意是**实际**，不是计划 —— 两者的差距才是这个 pipe 的价值。

## 步骤

1. 对目标区间逐天 `timeline()`，收集应用与窗口标题序列。
2. 从窗口标题里提取**项目名、仓库名、文档名**（不是应用名 ——
   「用了 6 小时 Chrome」是没有信息量的一维数据）。
3. `recall("我在推进什么")` 取语义层面的主线。
4. 对每条主线用 `search_screen()` 找起止时间。

## 输出

```
## 真正在推进的三件事
每件写：什么时候开始的、最近一次碰是什么时候、进展到哪。

## 开了头没继续的
列出来。不评价，只陈述。

## 计划外占用
明显不在主线上、但确实花了时间的事。
```

## 硬要求

- **按项目/主题聚合，不按应用聚合。** 应用时长是最没信息量的维度。
- **不做价值判断**，不说「你应该减少 X」。这是记录不是教练。
- 「开了头没继续的」只陈述事实，让人自己判断要不要捡起来。
