# 周报生成

## 目标

从过去 7 天的工作记忆里，还原我**实际**做了什么，而不是我以为我做了什么。

## 步骤

1. `capture_status()` —— 先确认这 7 天有数据。缺天数要在报告里说明，不要假装完整。
2. 对 `days_ago` 0 到 6 逐天调 `timeline()`，拿到应用与窗口序列。
3. `read_report(days_ago=N)` 逐天读已有报告，补充细节。
4. 对时间线里反复出现的项目名/仓库名，用 `search_screen(keyword)` 取原文佐证。

## 输出

```
## 这周实际推进了什么
按项目分组，每项写：做到哪一步、卡在哪、有没有结论。
每条必须能指到具体证据（哪天几点、什么应用、原文片段）。

## 花了时间但没有结论的
诚实列出来。这些往往是下周要处理的。

## 未完成的待办
从报告的「待办」项里汇总，标注是哪天提到的。
```

## 硬要求

- **只写记录里真实出现过的**。没有证据的推断一律不写。
- **不做效率点评、不给改进建议、不统计时长** —— 这些没有决策价值。
- 具体优先于概括：写「修 40164 IP 白名单」，不写「解决了技术问题」。
- 数据缺失时明说「X 月 X 日无记录」，不要用其他天的内容填补。
