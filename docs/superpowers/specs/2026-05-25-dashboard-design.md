# 看板设计文档

## 概述

为 captureScreen 项目添加一个终端 TUI 看板（`dashboard.py`），基于 Textual 框架。三列全屏布局，用于个人回顾每日活动，支持控制、搜索、标注。

## 使用场景

个人回顾工具，查看每天时间花在哪里、做了什么，并对活动记录进行分类标注和任务跟踪。

## 技术选型

- 框架：Textual（已安装）
- 数据源：本地文件系统（screenshots/、reports/、annotations.json）
- AI 查询：复用现有 query.py 逻辑（GLM-4.6V-Flash 免费模型）

## 布局设计

三列全屏，顶部 Header 显示时钟+系统状态，底部 Footer 显示快捷键。

```
┌─────────────┬──────────────────┬───────────────────────────┐
│   菜单      │    报告列表       │       内容面板             │
│             │                  │                           │
│ ● 系统状态  │ 05-25 16:00  ◄  │ # 16:00 - 16:59 活动报告  │
│ ● 小时报告  │ 05-25 15:00     │                           │
│ ● 日总结    │ 05-25 14:00     │ ## 活动时间线              │
│ ● 周报      │ 05-22 11:00     │ - 16:00-16:30 ghostty     │
│ ● 月报      │                  │                           │
│ ─────────── │                  │ ## AI 分析内容             │
│ ● 标签管理  │                  │ ...                       │
│ ● 搜索      │                  │                           │
│ ─────────── │                  │ ## 标注                    │
│ [Start]     │                  │ 🏷 写代码 / 跟进中         │
│ [Analyze]   │                  │ 📝 备注文字...             │
│ 状态: 运行中│                  │                           │
└─────────────┴──────────────────┴───────────────────────────┘
│ r:刷新 s:搜索 /:标注 q:退出                              │
└───────────────────────────────────────────────────────────┘
```

### 列宽

- 左列：20 字符（菜单 + 控制 + 状态）
- 中列：35 字符（报告时间线）
- 右列：自适应剩余宽度（内容 + 标注）

### 左列：菜单区

菜单项（ListView，可上下选择）：
1. 系统状态 — 显示截图进程状态、今日统计
2. 小时报告 — 按时间倒序列出所有小时报告
3. 日总结 — 列出所有日总结
4. 周报 — 列出周总结
5. 月报 — 列出月总结

分隔线后：
6. 标签管理 — 查看所有标签、按标签筛选报告
7. 搜索 — 触发搜索

分隔线后（控制区）：
- Start/Stop 按钮 — 启动/停止截图采集
- Analyze 按钮 — 手动触发 AI 分析
- 状态文字 — 运行中/未运行 + 今日截图数

### 中列：报告列表

- 按菜单选择过滤报告类型
- 每条显示：日期 + 时间/类型标识
- 选中项高亮，右侧面板同步显示内容
- 搜索模式下显示搜索结果

### 右列：内容面板

- Markdown 渲染报告内容（时间线 + 时间分配 + AI 分析）
- 底部显示该报告的标注信息（标签 + 备注 + 状态）
- 无标注时显示"按 / 添加标注"提示

## 标注系统

### 存储格式

`annotations.json`（项目根目录），按日期+小时索引：

```json
{
  "2026-05-25": {
    "14": {
      "tags": ["写代码", "研究"],
      "note": "在研究智谱 API 接入",
      "status": "done"
    },
    "15": {
      "tags": ["阅读"],
      "status": "todo"
    }
  }
}
```

### 标注字段

- **tags**：字符串数组，时间分类标签，自由输入
- **note**：字符串，自由文字备注
- **status**：枚举，`done`（已完成）/ `todo`（待跟进）/ `none`（未标记）

### 交互方式

- 按 `/` 弹出行内编辑面板（Textual Modal）
- 面板包含三个输入框：标签（逗号分隔）、备注、状态（下拉选择）
- 保存后写入 annotations.json，右侧面板即时更新
- 常用标签自动从 annotations.json 历史中提取建议

## 控制功能

### 启动/停止截图

- 点击 Start 按钮或按快捷键：`subprocess.Popen` 启动 `capture.py`
- 点击 Stop 按钮或按快捷键：读取 PID 文件，发送 SIGTERM
- 按钮状态跟随实际进程：运行中时 Stop 可用、Start 灰显

### 手动触发分析

- 点击 Analyze 按钮或按快捷键：执行 `analyze.py`
- 分析期间按钮显示 loading 状态
- 完成后自动刷新报告列表

## 搜索功能

- 按 `s` 弹出行内搜索框
- 输入自然语言或关键词
- 实现方式：扫描 reports/ 目录下的 .md 文件，关键词匹配
- 搜索结果显示在中间列，替换当前列表
- 按 `Esc` 恢复原始报告列表

## 快捷键

| 键 | 功能 |
|----|------|
| `q` | 退出看板 |
| `r` | 刷新所有数据 |
| `s` | 打开搜索 |
| `/` | 编辑标注 |
| `Enter` | 确认/打开 |
| `Esc` | 取消/返回 |
| `Tab` | 切换列焦点 |
| `j/k` 或 ↑↓ | 列表上下移动 |

## 文件结构

```
dashboard.py        # 主程序（Textual App）
annotations.json    # 标注数据（运行时生成）
```

dashboard.py 包含：
- `DashboardApp` — 主 App 类
- `MenuColumn` — 左列菜单组件
- `TimelineColumn` — 中列报告列表组件
- `ContentColumn` — 右列内容+标注组件
- `AnnotationModal` — 标注编辑弹窗
- `SearchModal` — 搜索弹窗
- `scan_reports()` — 扫描报告文件
- `load/save_annotations()` — 标注读写
